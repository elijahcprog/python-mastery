# Day 1 LeetCode: 1108. Defanging an IP Address (Easy)

**Link:** https://leetcode.com/problems/defanging-an-ip-address/

## The problem, in plain words

You're given a valid IPv4 address as a string, such as `"1.1.1.1"`. Return a copy where every dot `.` is replaced by `[.]`.

`"1.1.1.1"` → `"1[.]1[.]1[.]1"`

**Why this is a real security task:** analysts "defang" IP addresses and links in reports so nobody can click them or connect to them by accident.
